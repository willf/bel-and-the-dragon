# Bel and the Dragon

Greek texts of **ΒΗΛ ΚΑΙ ΔΡΑΚΩΝ** (_Bel and the Dragon_) in the Old Greek and Theodotion versions, provided as plain text and Word documents.

## Files

| Version    | Plain text                       | Word document                      |
| ---------- | -------------------------------- | ---------------------------------- |
| Old Greek  | [old-greek.txt](old-greek.txt)   | [old-greek.docx](old-greek.docx)   |
| Theodotion | [theodotion.txt](theodotion.txt) | [theodotion.docx](theodotion.docx) |

The plain-text files contain polytonic Greek and verse numbers. Open them in a UTF-8-compatible text editor with a font that supports polytonic Greek. The Old Greek text includes verse-number placeholders such as `12-` where no text is supplied.
